# Changi route maps

Live map: https://eadgpt.github.io/changi-china-flights

An interactive 3D map of the flights from Singapore Changi (SIN) to **China, Indonesia and Vietnam**.
Switch country with the buttons at the top of the panel.

- Every airport Changi flies to, with its flights per week, days flown, airlines and flight numbers
- Non-stop flights (solid lines), one-stop same-plane flights (dashed), cities that need a change of planes, and routes that have not come back
- Search by city, province, airport code or airline; compare two cities; light and dark themes; 2D or 3D view
- `index.html` runs on its own with no internet — everything is inside the one file

Sources: Changi's airlines-and-destinations list on Wikipedia and flightsfrom.com timetables (non-stop), checked 23 Sep 2026.
Airlines change schedules often, so treat the numbers as a guide.
